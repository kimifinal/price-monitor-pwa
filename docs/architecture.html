Price Monitor PWA — 架構 / 數據流

真相來源 = git 可 diff 的 JSON（時序 / gate / 去重）；判定只一處（前後端鏡像）；離線安全為硬 AC。 現階段純 Costco，加密貨幣現階段排除。

單一真相來源（SSOT）

  • history_data.json — 時序（git-diffable，非 .db）
  • watchlist.json — 告警 gate（獨立於時序）
  • alerts_state.json — 去重
  • .db 是 transient，啟動即從 JSON 重灌

判定只一處

  • models.price_verdict（後端）
  • monitor.js.priceVerdict（前端鏡像）
  • 前後端測試互守「同一條規則」
  • verdict：below_target / all_time_low / good_deal

離線安全（硬 AC）

  • 抓取皆有確定性 fallback → 無網 CI 仍綠
  • 合成資料永不觸發告警
  • SW 快取 API + 快照，全離線可用
  • 排程刷新預設 sink=log，不污染
